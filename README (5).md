## 📋 Task Overview

> **PRODIGY_SD_01** — Software Development Internship

Build a program that converts temperatures between **Celsius**, **Fahrenheit**, and **Kelvin** scales. The program prompts the user to input a temperature value and its original unit, then converts and displays the value in the other two units.

---

## 🧮 Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius → Fahrenheit | `F = (C × 9/5) + 32` |
| Celsius → Kelvin | `K = C + 273.15` |
| Fahrenheit → Celsius | `C = (F − 32) × 5/9` |
| Kelvin → Celsius | `C = K − 273.15` |
